# 老人言 · 公司管理台

老人言程序制作有限公司的内部经营管理工作台。纯前端静态站点，不需要后端、构建工具或网络依赖。

## 打开方式

直接双击 `index.html`，用 Chrome、Edge 或其他现代浏览器打开即可。

如果浏览器对 `file://` 页面的本地存储有限制，可在当前目录启动一个静态服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 页面

- **数据看板**：总营收、总支出、经营结余、公司市值；CNY / USD / EUR / HKD / JPY 切换；12 个月营收支出趋势、支出构成、业务板块与近期流水。
- **合作与集团**：合作公司名录、集团成员总览、添加合作公司、筛选与分页。
- **存入与转出**：多币种资金概况、三个结算账户、月度资金流向、记录流水、确认待结算记录。
- **客户信息**：客户名录、信任交易额、添加客户、筛选与分页。
- **服务与团队**：服务项目总览、新增服务、员工档案、添加员工与部门筛选。
- **股市数据**：指数概览、自选行情、价格与成交量图、区间切换、内部研究摘要。

顶部搜索框可检索合作公司、集团成员、客户、交易记录、员工、服务与股票。`Ctrl / ⌘ K` 聚焦搜索，`↑ / ↓` 选择结果，`Enter` 打开，`Esc` 关闭浮层。

## 数据

- 首次打开会载入一组完整的初始经营数据。
- 新增的合作公司、客户、流水、员工与服务会自动保存在当前浏览器的 `localStorage` 中。
- 通过右上角账户菜单中的“恢复初始数据”可以回到初始状态；该操作会覆盖本机已保存的内容。
- 币种折算使用固定的内部中间价（1 CNY = 0.1406 USD / 0.1294 EUR / 1.0943 HKD / 21.36 JPY），仅用于经营总览。
- 股市行情为收盘快照与内部研究摘要，不构成投资建议。

## 文件

- `index.html` — 页面入口、静态外壳与 SVG 图标
- `styles.css` — 视觉系统与响应式布局
- `app-core.js` — 数据、格式化、路由、搜索、通知与图表交互
- `app-pages.js` — 六个页面的渲染与图表构建
- `app-ui.js` — 弹窗、抽屉、表单与导出
- `app.js` — 表单提交、动作处理、事件绑定与初始化
